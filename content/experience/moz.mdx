product (ExtJS + Rails), onto Next.js, TypeScript and MUI. First hire on the new
frontend team: worked from the first shared components through the MozCon demo,
closed beta (Oct 2024) and feature parity, then the 2025–2026 pivot to AI-search
(GEO) features. Later led features end to end across the TypeScript frontend and
Ruby backend, set the team's testing and code standards, and drove AI-tooling
adoption.
