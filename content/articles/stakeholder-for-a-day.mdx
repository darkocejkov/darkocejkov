i felt like the stakeholder, just for one day
- david bowie (not really)

when i had the power of agents in my hands I made every little idea my little brain could squeeze from its folds.
even when working on tickets, i stopped caring about code quality and only looked at return.
is the code doing the thing? is it working? that's it.
it was a suspicious high, it was too fun watching the agent work and not ask me questions (auto mode, nice).
days later the high wears off because i now have 15+ PRs to handle. i think the worst part is that
i passed them to my team, who then had to review thousands of barely-reviewed code and point out very obvious things
that i had missed. 
i got caught up in being able to get 80% of the work done, then i spent weeks longer getting that 20% in.
i couldn't answer questions about the code because i didn't write it, nor did i understand it.

i vow to review my code before i submit it.
